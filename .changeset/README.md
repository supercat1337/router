# Changesets

Hello and welcome! This folder has been automatically generated by
[`@changesets/cli`](https://github.com/changesets/changesets), a build tool
that works with your source code to manage versioning and changelog updates.

## Workflow

When you make a change that should be released:

```bash
npm run changeset
```

Answer the prompts (patch / minor / major, description). A new markdown
file appears in `.changeset/` — commit it alongside your code. On release:

```bash
npm run version-packages   # bump version, update CHANGELOG.md
git add . && git commit -m "chore: version packages"
npm run publish-packages   # publish to npm
```

See [`VERSIONING.md`](../VERSIONING.md) for the full policy.
